## 📌 Overview

This repository contains lab code, simulations, and algorithmic implementations for **Digital Electronics and Circuit Theory** courses in Computer Science & Engineering (CSE).

---

## ✨ Topics Covered

- 🔌 **Boolean Logic Gates**: AND, OR, NOT, NAND, NOR, XOR logic modeling.
- 🧮 **Combinational Logic Circuits**: Adders, Subtractors, Multiplexers (MUX), and Demultiplexers (DEMUX).
- 🔄 **Sequential Circuits**: Flip-flops, Counters, Shift Registers, and State Machines.

---

## 🛠️ Built With

- **Language**: C++ (C++11 / C++17)
- **Compiler**: GCC / Clang / MSVC

---

## 💻 How to Compile & Run

```bash
# Clone repository
git clone https://github.com/SaymoonIslam/Electronic-Lab.git

# Navigate into directory
cd Electronic-Lab

# Compile C++ source files
g++ -O2 main.cpp -o main

# Run executable
./main
```
